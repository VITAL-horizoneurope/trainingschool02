# VITAL Training School 02
February 9-12 2026, Auckland, New Zealand

Coordinator/organisers: Gonzalo Maso Talou (coordinator), Peter Hunter, Beatrice Ghitti.  
Lecturers: Vijay Rajagopal, Peter Hunter, Harvey Davis, Finbar Argus, Evelien Hermeling, Maartje Hoogeveen, Beatrice Ghitti, Alberto Zingaro, Mathias Peirlinck, Francisco Sahli Costabal, Alessandro Giudici, Gonzalo Maso Talou and Thiranja Prasad Babarenda Gamage.

The repository is organised by day and lecturers of the training school. Each lecture is combined with a tutorial/hands-on session. The directory ``Tutorials_with_Docker/`` includes several tutorials that can be run using Docker.

Further instructions supporting each tutorial can be found in the ``README.md`` file of each subdirectory.
