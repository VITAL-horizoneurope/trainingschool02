## Tutorials 2 & 5

These tutorials will use Circulatory_Autogen, a software designed for generating and calibrating computational models (CellML or 1D finite volume).

### First step: Clone Circulatory_Autogen

From the directory ``trainingschool02/Tutorials_with_Docker/tutorial_2_5_Argus_Ghitti_Davis`` call this command **TODO**
```bash
git clone https://github.com/FinbarArgus/circulatory_autogen.git --branch devel_interactive_tutorial
cd circulatory_autogen
```
### Jupyter notebooks

Jupyter notebooks of both tutorials are located in ``circulatory_autogen/tutorial/interactive``, together with all related scripts and resources:
- ``generation_and_calibration.ipynb`` runs the cardiovascular model generation and calibration tutorial,
- ``image_to_hemodynamics_model.ipynb`` runs the tutorial from anatomical images to functional models.

### Download images

To run the ``image_to_hemodynamics_model.ipynb`` tutorial, you will need the confocal microscope images. Download the zip file from **TODO** and extract it in ``circulatory_autogen/tutorial/interactive/resources/``.
